# 路线图

<strong>中文</strong> | <a href="roadmap.md">English</a>

Open Island 由社区驱动。欢迎围绕当前本地 macOS 产品边界的贡献。

Open Island 是仅本地运行的 macOS island 外壳，带有受约束的本地 agent
通信层。路线图中的想法必须保持这个边界，除非另有独立的产品和安全决策。

当然你也可以 fork 自己的版本并任意改造，不过 PR 到这里有机会让它被更多人使用（btw，我们使用 GPL 协议）。

> **如何参与**：
> 1. 在 issue 中清晰描述你的想法，然后提交 PR。
> 2. 在有任意代码（或其他形式的贡献）被合并后，你可以选择成为 maintainer 之一，只需要联系 [@Octane0411](https://github.com/Octane0411)。

## 重点方向

| # | 方向 | 说明 | 状态 | 链接 |
|---|------|------|------|------|
| 1 | **Code Agent 集成体验** | 改进当前受支持的本地 agent 集成和显式 hook 管理。 | 活跃 | — |
| 2 | **本地跳转** | 在不进行终端命令注入或远程控制的前提下，改进受支持的 Terminal.app、Ghostty 和 iTerm2 聚焦行为。 | 已规划 | — |
| 3 | **本地交互体验提升** | 改进 UX、UI、动画、音效和本地辅助功能体验。 | 开放 | — |
| 4 | **本地产品想法** | 语音、通知回复等想法只有在保持已记录的“仅本地”边界时才会考虑。 | 有条件的开放 | — |
| 5 | **架构与代码质量** | 欢迎能让本地产品更易验证、恢复和维护的贡献。 | 开放 | — |

**状态说明**：`活跃` = 核心团队重点 · `已规划` = 已接受，未开始 · `开放` = 社区驱动，欢迎所有贡献 · `有条件的开放` = 需要先发起 issue 描述功能或讨论
